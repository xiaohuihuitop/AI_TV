# 技术交接与使用说明

## 1. 当前服务器端功能清单
- 视频管理：上传（仅 MP4）、列表、详情预览、删除
- 视频处理：宽>高自动旋转 90°、时长提取、10% 进度截图封面
- 文档管理：上传（仅 HTML）、列表、详情预览、删除
- Web 管理后台：侧边栏切换视频/文档管理；各自页面上传与删除
- API：视频/文档列表、详情、下载（视频支持 Range 断点）
- Public：App 清单协议（index.json + 资源直链）
- 鉴权：Basic Auth（Web 与 API 共用）
- 存储：本地目录 `data/` + SQLite

## 2. 运行与使用（Windows，Python 版本）
### 2.1 环境要求
- Python 3.10+
- ffmpeg + ffprobe（需加入 PATH）

### 2.2 安装依赖
```bash
python -m pip install -r requirements.txt -r requirements-dev.txt
```

### 2.3 启动服务
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### 2.4 访问入口
- Web：`http://127.0.0.1:8000/web/videos`
- API：`http://127.0.0.1:8000/api/videos`
- Public：`http://127.0.0.1:8000/public/index.json`

### 2.5 账号密码
- 用户名：admin
- 密码：admin

### 2.6 Public 协议说明
- 清单地址示例（Basic Auth）：`http://admin:admin@127.0.0.1:8000/public/index.json`
- 清单地址示例（Query Auth）：`http://127.0.0.1:8000/public/index.json?user=admin&pass=admin`
- 资源地址会自动包含同一认证信息，App 可直接下载/播放

```

│  └─ web/                  # Web 路由
├─ AI_TOOL/                 # 测试脚本（含说明）

├─ data/                    # 运行时数据（SQLite + 文件）

├─ requirements-dev.txt     # 测试依赖
└─ pytest.ini               # 测试配置
```

> 说明：`data/` 为运行时目录，会在服务启动后自动生成。

## 4. 配置说明
配置位于 `app/core/config.py`：
- `data_dir`：数据目录（默认 `./data`）
- `db_path`：SQLite 路径（默认 `./data/db/app.db`）
- `basic_user` / `basic_pass`：后台账号密码
- `worker_interval_sec`：后台处理轮询间隔（秒）

可通过环境变量覆盖（如需要）：
- `DATA_DIR`、`DB_PATH`、`BASIC_USER`、`BASIC_PASS`、`WORKER_INTERVAL_SEC`

## 5. 数据与状态说明
- 视频状态：`pending` → `processing` → `ready` / `failed`
- 文档状态：默认 `ready`
- 视频封面：生成后保存在 `data/covers/`，列表与详情会显示

## 6. 常见问题
1) **视频上传后暂时无法预览**：属于异步处理，等待状态变为 `ready`。
2) **服务重启后数据不见**：请确认启动目录一致，确保 `data/` 未被删除。
3) **ffmpeg 未安装**：会导致旋转/截图/时长提取失败。

## 8. 维护与迭代建议
- Web 与 API 均使用 `files` 字段进行多文件上传
- 若需要多用户权限，建议替换 Basic Auth 为 JWT
- 若并发量上升，建议将后台任务改为独立进程或队列
