# App端开发流程与效果总结

## 1. 概述
App 端基于 uni-app（Vue 3）实现，面向“内容清单 + 离线缓存 + 播放/阅读”的轻量内容分发与消费场景。界面整体为暖色纸感卡片风格，橙色作为强调色。

## 2. 页面结构与效果

### 2.1 最新页
- 页面路径：`pages/latest/index`
- 效果：标题 + 副标题、视频/图文胶囊切换、卡片列表、封面缩略图与下载按钮。
- 功能：从清单加载内容，支持下拉刷新与缓存回退。

### 2.2 离线页
- 页面路径：`pages/offline/index`
- 效果：与最新页一致的切换与卡片布局，下载中显示进度条与百分比。
- 功能：展示离线缓存内容，支持删除。

### 2.3 设置页
- 页面路径：`pages/settings/index`
- 效果：清单地址输入框 + 保存按钮 + 保存提示。
- 功能：配置清单地址并本地持久化。

### 2.4 播放页
- 页面路径：`pages/player/index`
- 效果：黑底视频播放器，结束后重播浮层，底部返回/上一条/下一条按钮。
- 功能：视频播放与队列切换。

### 2.5 图文阅读页
- 页面路径：`pages/reader/index`
- 效果：卡片内容区、Markdown 渲染（标题/引用/代码块/表格样式）。
- 功能：加载并阅读 Markdown 内容，支持远端与本地。

## 3. 开发与运行流程（核心链路）

### 3.1 清单地址配置
- 入口：设置页
- 本地存储键：`index_url`
- 说明：作为全局内容入口。

### 3.2 最新页加载
1. 读取 `index_url`。
2. 请求清单（index.json）。
3. 成功：写入 `index_cache` 并渲染；失败：回退 `index_cache`。
4. 数据归一化并按 `published_at` 倒序排序。
5. 按 `type` 分流为视频/图文列表。

### 3.3 离线下载
1. 点击“下载”加入 `download_items`。
2. 使用 `uni.downloadFile` 下载，`uni.saveFile` 保存。
3. 记录 `status` / `progress` / `local_path`。
4. 离线页 500ms 轮询刷新进度。

### 3.4 播放与阅读
- 视频：写入 `player_queue` 与 `player_queue_index`，进入播放页。
- 图文：进入阅读页，读取 Markdown 内容。

## 4. 本地存储键
- `index_url`：清单地址
- `index_cache`：清单缓存
- `download_items`：离线下载记录
- `player_queue`：播放队列
- `player_queue_index`：播放队列当前索引

## 5. 服务端对接规范（最小契约）

### 5.1 index.json 示例
```json
{
  "items": [
    {
      "id": 1001,
      "type": "video",
      "title": "示例视频",
      "url": "https://example.com/videos/intro.mp4",
      "cover": "https://example.com/videos/intro.jpg",
      "published_at": "2026-02-01T10:00:00Z"
    },
    {
      "id": 2001,
      "type": "article",
      "title": "示例图文",
      "url": "https://example.com/articles/guide.md",
      "cover_url": "https://example.com/articles/guide.jpg",
      "published_at": "2026-02-01T09:00:00Z"
    }
  ]
}
```

### 5.2 字段说明
- `id`：唯一且稳定，离线/播放队列依赖该字段去重与定位。
- `type`：`video` 或 `article`。
- `title`：展示标题。
- `url`：资源地址（视频/Markdown）。
- `cover`/`cover_url`：封面图（可选）。
- `published_at`：用于排序（建议提供）。

### 5.3 封面推导规则
- 当 `cover`/`cover_url` 缺失时，会基于 `url` 默认替换扩展名为 `.jpg`。

## 6. 视觉与交互要点
- 背景：暖色渐变纸感。
- 卡片：圆角 + 轻阴影。
- 按钮：44px 触控高度，橙色为主动作。
- 动效：列表入场淡入上升（`rise-fade`）。

## 7. 关键代码位置
- 页面：`app/pages/**`
- 全局样式：`app/uni.scss`
- 清单归一化：`app/utils/indexService.js`
- 离线下载：`app/utils/offlineService.js`
- 播放队列：`app/utils/playerQueue.js`
- 文件读取：`app/utils/fileService.js`
