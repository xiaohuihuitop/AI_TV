# 项目交接与现状总结（2026-02-04）

## 1. 项目概述
- 目标：搭建“内容清单 + 上传管理 + App 消费与离线”的轻量内容系统。
- 形态：`server` 提供上传/处理/清单/API；`android` 为 uni-app 客户端展示/下载/播放/阅读。
- 核心约束：以 App 协议为主，服务端需适配；账号密码共用（后台与 public）。

## 2. 需求与范围（现行）
### 2.1 功能需求
- 服务端
  - 视频：上传（MP4）、列表、详情预览、删除、处理（旋转/时长/封面）
  - 文档：上传（HTML）、列表、详情预览、删除
  - Public：输出清单 `index.json` 与资源直链
  - 鉴权：Basic Auth（Web 与 API 共用）
- App 端
  - 最新页：读取清单、缓存回退、视频/图文切换
  - 离线页：下载进度、离线播放/阅读、删除
  - 播放页：视频播放与队列切换
  - 阅读页：Markdown/HTML 渲染（离线优先）
  - 设置页：配置清单地址

### 2.2 不做范围（YAGNI）
- 多用户权限、用户注册
- 高并发分发优化、分布式存储
- 复杂全文检索

## 3. 当前实现进度
### 3.1 服务端（完成）
- public 协议与清单输出已实现（index.json）
- 视频/文档管理、删除、上传交互、侧边栏分流已完成
- 视频处理链路可用（依赖 ffmpeg/ffprobe）

### 3.2 App 端（已完成主体）
- 清单读取、缓存、视频/图文切换、离线下载、播放/阅读
- 离线文档保存路径改为固定 `_doc/article_<id>.html`
- 离线 HTML CSP 清理：下载时清理 + 阅读页二次清理

## 4. 协议与对接
### 4.1 Public 清单
- 示例：
```json
{
  "items": [
    {
      "id": 4,
      "type": "video",
      "title": "xxx.mp4",
      "url": "http://127.0.0.1:8000/public/videos/4/download?user=admin&pass=admin",
      "cover": "http://127.0.0.1:8000/public/videos/4/cover?user=admin&pass=admin",
      "published_at": "2026-02-03T02:22:26.502975"
    },
    {
      "id": 3,
      "type": "article",
      "title": "xxx.html",
      "url": "http://127.0.0.1:8000/public/docs/3/download?user=admin&pass=admin",
      "published_at": "2026-02-03T02:22:26.470090"
    }
  ]
}
```
- Auth：支持 Basic 或 query（`user/pass`），App 建议用 query。

## 5. 运行与开发
### 5.1 服务端
- 依赖：Python 3.10+，ffmpeg/ffprobe
- 启动：
```
uvicorn app.main:app --host 0.0.0.0 --port 8000
```
- 入口：
  - Web：`/web/videos`
  - API：`/api/videos`
  - Public：`/public/index.json`

### 5.2 App
- HBuilderX/uni-app 运行
- 设置页配置清单地址（index.json）
- 离线下载依赖 `uni.downloadFile` + `uni.saveFile`

## 6. 关键配置/存储
- 服务端配置：`server/app/core/config.py`
  - `basic_user/basic_pass`
  - `data_dir/db_path`
- App 本地存储键：
  - `index_url`、`index_cache`、`download_items`、`player_queue`

## 7. 已知问题与风险
### 7.1 未解决问题
- **离线 HTML unsafe-eval 报错仍偶发**：即便清理 CSP，部分 HTML 内联脚本仍触发 eval。
  - 建议排查：HTML 原文是否包含 CSP 或 eval 类脚本。
  - 备选方案：阅读页统一改为 `mp-html` 渲染（跳过 web-view）。

### 7.2 代码卫生
- `android/unpackage/dist/dev/**` 为构建产物，建议清理或加入 `.gitignore`。

## 8. 后续建议（明确执行顺序）
1. 固定离线 HTML 渲染策略（二选一）
   - 方案A：继续 web-view，移除/替换 HTML 中脚本与 CSP
   - 方案B：离线统一转 Markdown 或纯文本，用 mp-html 渲染
2. 统一离线下载状态：`local_path` 为空即失败
3. 清理构建产物并规范 `.gitignore`

## 9. 交接清单
- 确认清单地址与账号密码
- 确认 ffmpeg/ffprobe 在 PATH
- 确认 App 设置页 `index_url` 正确
- 清理旧离线文件后重新下载验证
- 如接手开发，优先处理“unsafe-eval”问题
