# 影院质感 UI 设计说明

## 目标
- 统一为“影院质感”暗色视觉：高对比、沉浸、内容为主。
- 在移动端保持清晰可读与操作可点（触控目标 ≥ 44px）。

## 设计方向
- 风格：OLED 深色 + 暖橙点缀 + 低对比纹理光晕。
- 语气：克制的高级感，强调内容与层级。

## 色彩与层级
- 背景：深靛黑渐变（冷到暖的双向光源），避免纯黑死板。
- 表面：深色半透明卡片，带柔和边框与轻阴影。
- 主色：暖橙用于按钮与进度条，辅助浅色用于高对比文本。
- 边框：低对比细线用于分隔，避免“发灰”。

## 字体与排版
- 标题使用衬线（片名感），正文使用无衬线增强可读性。
- 正文行高 1.6，标题略收紧字距。
- 重要信息强化字号与重量，次要信息保持 12-13px。

## 组件策略
- 头部：标题 + 副标题层级更清晰，加入轻微入场动效。
- 标签切换：胶囊样式，高亮态带微光与描边。
- 列表项：卡片条目化，内容区与操作区拉开层级。
- 进度条：暖橙渐变，进度百分比贴近内容。
- 表单：深色输入框 + 清晰聚焦态，按钮保持高对比。

## 动效与反馈
- 页面与卡片使用 150-250ms 渐入上浮。
- 列表条目轻微分批（stagger）显示。
- 按钮与切换仅做颜色/阴影过渡，避免位移。

## 可访问性
- 文本对比度 ≥ 4.5:1。
- 点击元素具备清晰反馈与 44px 触控区域。
- 在暗色背景保持可读性与清晰焦点状态。
