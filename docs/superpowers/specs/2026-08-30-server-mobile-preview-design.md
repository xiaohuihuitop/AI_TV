# 服务端手机播放器预览设计

## 目标

在服务端“视频管理”页面为可播放视频提供手机模型预览，让管理员直接查看视频在手机客户端全屏播放器中的画面比例、横竖屏方向及“上一个 / 返回 / 下一个”按钮状态。

## 已确认范围

- 入口采用视频条目中的“手机预览”按钮，点击后在当前页面打开模态弹窗。
- 仅预览播放器，不增加手机客户端“最新”列表模拟。
- 视频宽大于高时显示横向手机模型，其他情况显示纵向模型。
- 视频区域固定使用 `object-fit: contain`，不裁切、不拉伸。
- 弹窗内播放真实服务器视频；不自动播放，管理员显式点击播放器控制条开始播放。
- 弹窗底部固定显示“上一个 / 返回 / 下一个”，视觉使用手机客户端沉浸播放器的深色按钮条与绿色返回按钮；横屏模型以客户端视频区加 76px 操作栏的整体比例留出空间。
- “上一个 / 下一个”在当前页面已渲染且状态为 `ready` 的视频序列中切换；首条禁用“上一个”，末条禁用“下一个”。
- “返回”、关闭按钮、按 Escape、点击弹窗外区域都会暂停播放并关闭预览；Escape 由显式键盘事件处理，不只依赖浏览器对 `<dialog>` 的默认行为。

## 不做

- 不修改 Android 客户端代码、播放协议或清单认证方式。
- 不模拟 Android 系统栏、原生视频控件像素级外观或离线文件播放。
- 不新增服务端持久化数据、接口权限规则或第三方前端依赖。
- 不让 pending、processing 或 failed 视频进入播放器预览。

## 页面与数据流

1. `videos.html` 对每个 `ready` 视频输出一个“手机预览”按钮，并在页面中输出该视频的 ID、标题、下载 URL、宽高。
2. 同一模板在页面内收集当前筛选结果中全部 `ready` 视频，作为仅前端使用的预览队列；队列顺序与当前视频管理列表保持一致。
3. `mobile-preview.js` 接收按钮点击，设置当前队列索引，填充 `<dialog>` 中的标题、视频地址和手机模型方向。
4. 浏览器 `<video>` 使用现有受 Basic Auth 保护的 `/api/videos/{id}/download` 地址播放；预览请求复用当前后台登录会话，不新增公开地址。
5. 方向切换时仅切换手机模型 CSS 类和视频 `src`；视频加载失败时在手机屏幕区域显示错误文案，三个底部按钮仍保留。

## 组件边界

### Jinja 模板

- `server/app/templates/videos.html` 负责预览按钮、预览队列数据和语义化 `<dialog>` 结构。
- 弹窗有可访问名称、关闭按钮和用于播放失败的状态区域。

### 前端脚本

- 新建 `server/app/static/mobile-preview.js`。
- 负责打开/关闭、队列前后切换、禁用状态、横竖模型类、视频加载错误及播放资源释放。
- 不调用新 API，不保存状态到数据库或 localStorage。

### 样式

- `server/app/static/app.css` 增加预览按钮、遮罩、手机外框、黑色视频区域和底部按钮条样式。
- 预览区域使用固定纵横比避免页面抖动；在窄桌面窗口中自动缩放，不产生横向滚动。
- 保留浏览器视频控件用于实际播放；底部三个按钮模拟 Android 应用导航行为。

## 交互和可访问性

- 不自动播放，避免后台列表一打开就产生声音或动态干扰。
- 关闭后清空视频地址并调用 `pause()`，停止网络读取和声音。
- 所有按钮保留可见焦点状态；禁用按钮使用原生 `disabled` 属性，颜色和透明度同时表达状态。
- 弹窗打开时焦点进入关闭按钮，关闭后焦点回到原“手机预览”按钮。
- 点击遮罩只关闭，不触发视频播放；底部三个按钮的最小高度为 48px。

## 验收

- ready 视频显示“手机预览”，其他状态不显示。
- 点击预览可在弹窗手机模型中播放真实视频。
- 宽高为横向和竖向的视频分别呈现横向、竖向手机外框；画面完整可见。
- 首条、末条和中间条的视频按钮禁用状态正确，前后切换后同步更新标题、方向、`src` 和按钮状态。
- 返回、关闭、Escape、遮罩点击都关闭并停止视频。
- 无法播放时有明确错误提示，后台页面其他功能不受影响。
- 既有服务端后台特性测试和新增预览前端回归测试通过。

## 风险与验证

- 浏览器中的原生视频控制条无法与 Android 系统控件像素级一致；本功能验证的是内容比例、手机方向和应用内三个大按钮的实际布局。
- 管理页面使用 Basic Auth，真实浏览器验证时需确认下载 URL 复用后台认证并支持 Range 请求。
- 使用自动化浏览器覆盖 375px 宽度、横向手机模型、纵向手机模型、首尾按钮、键盘关闭和关闭后视频暂停。
