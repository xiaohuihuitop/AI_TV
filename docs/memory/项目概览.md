# 项目概览

- 项目目标：为长辈提供易读、少操作的视频和图文客户端，并配套 Docker 服务端管理内容。
- 核心技术：Android 客户端使用 uni-app App-Plus；服务端使用 Python Web 服务和 Docker；GitHub Actions 通过 `build-*` tag 构建服务端镜像。
- 关键模块：`android/` 为手机客户端，`server/` 为服务器，`AI_TOOL/` 为回归脚本。
- 长期约束：客户端视频不得裁切或拉伸；适老化操作必须保持大触控区域和清晰状态；服务端默认以 `ai_tv_server:latest` 交付，持久数据统一位于 `/data`，应用进程默认使用 UID/GID 10001。
- 默认连接：客户端使用 `https://tv.xiaohuihuitop.top/public/index.json?user=admin&pass=admin`，自动更新清单为 `https://tv.xiaohuihuitop.top/update/update.json`。
- 更新边界：页面、JavaScript、CSS 和业务逻辑通过 WGT 更新；Android 权限、原生插件、图标、包名和原生 manifest 变化仍需 APK。
