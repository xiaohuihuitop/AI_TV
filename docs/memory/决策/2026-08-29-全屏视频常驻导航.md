# 全屏视频常驻导航

- 状态：已确认
- 日期：2026-08-29
- 结论：手机端使用页面级沉浸式播放器，视频保持 `contain`，底部独立常驻“上一个、返回、下一个”；进入时先锁方向再隐藏系统栏，退出时锁回竖屏并恢复系统栏；恢复失败保留可重试状态，沉浸页不受全局最大宽度限制。
- 原因：原生视频全屏不能显示页面按钮；按钮覆盖视频不符合用户确认的布局；App-Plus 在先隐藏系统栏后旋转时会错误压缩播放器 WebView 高度。
- 影响：Android 播放器布局、方向切换、系统 UI 生命周期和相关回归测试。
- 相关文件：`android/pages/player/index.vue`、`android/utils/immersivePlayer.js`、`android/utils/layout.js`、`AI_TOOL/android_immersive_player_test.mjs`。
