# APK + WGT 自动更新

- 状态：已确认
- 日期：2026-09-01
- 结论：使用 APK + WGT，统一通过 `https://tv.xiaohuihuitop.top` 提供客户端清单和 WGT 更新，不依赖 GitHub。
- 原因：长辈手机可能无法访问 GitHub，且需要减少手动安装新版本的操作。
- 影响：页面、JavaScript、CSS 和业务逻辑通过 WGT 更新；Android 权限、原生插件、图标、包名和原生 manifest 变化仍需重新发布 APK。`/update/` 必须由反代提供持久化静态目录。
- 相关文件：`android/utils/updateService.js`、`android/App.vue`、`android/utils/appConfig.js`、`server/README.md`、`android/Doc/APP打包说明.md`
