# 播放器队列与切换设计

## 目标
- 最新/离线页面点击视频后，播放器支持“上一个/下一个”切换。
- 离线视频点击即可播放，仅对已完成下载的条目生效。
- 播放结束提供“重播”入口。

## 约束
- 不改动系统横竖屏，只扩大播放器窗口，视频内部保持横向显示。
- 离线数据以本地存储为准，未完成条目不可播放。
- 仅在需要处加注释，新增注释格式为 `AI:内容`，函数注释使用 Doxygen 风格。

## 数据模型
- 播放队列存储：
  - `player_queue`：数组，元素为 `{ id, title, url?, local_path?, type }`。
  - `player_queue_index`：当前索引。
- 读取策略：播放器先读队列+索引；无有效队列时回退使用路由 `src`。

## 关键流程
1) 最新页点击视频：
   - 构造 `videoItems` 队列（远程 `url`）。
   - 写入队列和当前索引后再 `navigateTo`。

2) 离线页点击视频：
   - 仅保留 `status === 'done'` 的视频条目，使用 `local_path`。
   - 若未完成则提示并返回。

3) 播放器页：
   - 读取队列并应用当前条目。
   - “上一个/下一个”切换时更新索引并复位结束状态。
   - `ended` 事件触发时显示“重播”，点击重播从 0 秒播放。

## 异常与降级
- 队列为空或索引越界：回退使用路由 `src`。
- 条目无可用地址：提示错误并阻止播放。

## 测试要点
- 最新页：点击视频进入播放器后可切换上一/下一。
- 离线页：下载完成后点击即播，未完成提示。
- 播放结束后显示重播，点击可从头播放。
