# Android 客户端响应式设计

## 目标

- 保留适合长辈使用的大字体和大触控区。
- 在 320dp 至 600dp 宽度以及横屏下不出现横向裁切。
- 修复播放器占满页面、底部操作被挤出的问题。
- 使用现有暖色视觉，不改变下载、离线播放和连接逻辑。

## 已确认问题

- 运行时全局样式写在 `android/uni.scss`，模拟器中页面留白、卡片和通用按钮样式没有生效。
- 视频卡片使用固定封面和不换行的信息标签，360dp 屏幕已出现右侧裁切。
- 播放器高度使用 `Math.max(baseHeight, maxHeight)`，会优先取接近整页的高度。
- 设置页按钮在窄屏下可能因为固定最小宽度溢出。

## 设计

1. 将运行时全局样式迁移到 `android/App.vue`，`uni.scss` 只保留编译期样式入口说明。
2. 视频卡片使用 `grid-template-columns: <cover> minmax(0, 1fr)`，信息标签允许换行；在小屏和宽屏分别调整封面尺寸与页面边距。
3. 提取纯函数计算播放器高度，按 16:9 首选高度和页面可用高度取较小值，并监听窗口尺寸变化。
4. 底部导航使用居中最大宽度与安全区；设置页按钮使用等宽网格；阅读区使用可用视口高度。

## 验证

- Node 回归脚本验证播放器高度和关键响应式样式约束。
- HBuilderX CLI 编译并运行到 MuMu 模拟器。
- 检查 360dp 竖屏、320dp 小屏和横屏；操作离线、最新、设置和播放页面。
