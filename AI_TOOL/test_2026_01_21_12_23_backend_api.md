# 后端接口测试脚本说明

## 用途
验证后端基础接口是否可用，覆盖健康检查、鉴权、视频上传、图文导入、删除与客户端只读接口。

## 使用方法
1. 确保 `backend` 代码已存在，且 `tv_data` 目录下有 `mp4` 文件。
2. 在项目根目录执行：

```powershell
python .\AI_TOOL\test_2026_01_21_12_23_backend_api.py --auto-start
```

可选参数：
- `--base-url`：服务地址（默认 `http://127.0.0.1:8000`）
- `--token`：管理端 Token（默认 `dev-token`）
- `--auto-start`：自动启动后端服务

## 预期结果
- 所有步骤输出 `[OK]`，最后输出“测试全部通过”。
- 若失败，输出 `[FAIL]` 并返回非 0 退出码。
